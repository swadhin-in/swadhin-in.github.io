## 🚀 Quick Start / Local Preview

You can open `index.html` directly in any web browser, or run a local server:

```bash
# Option 1: Using npx serve
npx serve -l 3000 .

# Option 2: Using Python HTTP server
python -m http.server 3000
```
Then visit `http://localhost:3000`.

## 📦 Deployment to GitHub Pages

Since this repository is linked to `https://github.com/swadhin-in/Swadhin.india.git`:

1. Commit and push the code:
   ```bash
   git add .
   git commit -m "feat: launch modern unique portfolio with clean white theme"
   git push origin main
   ```
2. On GitHub, navigate to **Settings > Pages**.
3. Under **Branch**, select `main` branch and `/ (root)`, then click **Save**.
4. Your portfolio will be live at `https://swadhin-in.github.io/Swadhin.india/` (or your custom domain).
